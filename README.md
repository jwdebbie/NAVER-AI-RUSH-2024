# AIME - 교제폭력 증거수집 AI 다이어리
> NAVER AI RUSH' 2024 프로젝트 | HyperCLOVA X 및 네이버 멀티모달 AI(CLOVA OCR/Speech) 기반 교제폭력 피해자 증거 수집 및 감정 기록 지원 서비스

---

## 1. 프로젝트 개요

교제폭력 피해자는 사건 직후 심리적 불안과 혼란으로 인해 사건 경위(누가, 언제, 어디서, 무엇을, 어떻게, 왜)를 체계적으로 기록하거나 관련 증거(메시지 캡처, 녹음 파일 등)를 수집하는 데 어려움을 겪습니다.

AIME는 피해자가 안전하고 정서적으로 보호받는 환경에서 대화를 나누며 사건의 핵심 사실관계를 수집하고, 멀티모달 증거 자료와 함께 일기 형태로 암호화 보관해 주는 AI 어시스턴트 서비스입니다.

---

## 2. 주요 기능 및 기여 사항

### 담당 역할
- 프롬프트 엔지니어링: HyperCLOVA X 모델 대상 과잉 공감(Over-empathy) 및 서사 환각(Hallucination) 방지 지침 설계
- 서비스 프로토타이핑: Figma 기반 사용자 인터페이스 및 대화 흐름 프로토타이핑
- 데모 앱 개발: 7대 필수 요소 수집을 위한 상태 기반 대화 제어(State Control) 및 Streamlit UI 개발

### 핵심 기능
1. 상태 기반 대화 제어
   - 7대 필수 요소(누가, 언제, 어디서, 무엇을, 어떻게, 왜, 증거 유무)를 자연스럽게 파악하기 위한 단계별 질문 상태 제어 로직 구현

2. HyperCLOVA X 기반 과잉 공감 및 환각 제어
   - 피해자가 명시적으로 감정을 표현하지 않은 상황에서 지나친 동정/공감을 남발하지 않도록 중립적 태도 유지
   - 입력되지 않은 서사(폭력 상황 묘사, 과도한 공포 등)가 임의로 추가되지 않도록 원문 보존 원칙 적용

3. 멀티모달 증거 수집 파이프라인
   - CLOVA OCR: 메신저 대화 스크린샷, 사진 등의 이미지 내 텍스트 자동 추출
   - CLOVA Speech (STT): 음성 녹음 파일의 텍스트 변환 및 증거화
   - 제출된 증거 및 요약 일기는 네이버 MY BOX에 암호화 보관되어 법적/행정적 참고 자료로 활용 가능

## 3. 시스템 아키텍처

```
[사용자 입력 (텍스트/이미지/음성)]
       │
       ├── 이미지 ──> CLOVA OCR API ──────────┐
       ├── 음성   ──> CLOVA Speech (STT) ─────┼──> [AIME Pipeline]
       └── 텍스트 ────────────────────────────┘         │
                                                        ▼
                                             [HyperCLOVA X]
                                      (상태 제어 & 프롬프트 가이드)
                                                        │
                                                        ▼
                                             [10문장 내외 '하루의 기록' 생성]
                                                        │
                                                        ▼
                                             [네이버 MY BOX 암호화 저장]
```

## 4. 프롬프트 엔지니어링 전략

HyperCLOVA X 모델 적용 시 다음과 같은 세분화된 지침을 시스템 프롬프트에 반영하였습니다.

```python
# prompt_config.py

SYSTEM_PROMPT = """
AI 어시스턴트 에이미(AIME)는 교제폭력 피해자가 피해 증거를 수집하고 일기를 작성하는 것을 돕는 AI 챗봇입니다.

[행동 가이드라인 및 공감 조절 규칙]
1. 과잉 공감 및 환각 금지:
   - 사용자가 직접 부정적 감정을 표현할 때만 2-3문장의 공감/지지를 제공합니다.
   - 감정을 표현하지 않거나 중립적인 사건 설명 시 "그런 일이 있으셨군요"와 같이 중립 응답을 유지합니다.
   - 사용자가 언급하지 않은 구체적 폭행 묘사나 감정을 임의로 덧붙여 생성하지 않습니다.

2. 순차적 상태 제어 (7대 필수 요소 수집):
   - 사건 질문 -> 증거 확인 -> 감정 확인 -> 공감 지지 -> 일기 작성 안내 순으로 상태를 전이합니다.
"""
```
